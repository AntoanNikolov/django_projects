### This is my personal django_projects folder. Projects inside it were made during the learning process of the DJ4E course.  

## HOW TO RUN:  
Download or clone to your computer  
Create and run virtual environment (optional)  
Navigate to mysite and run "pip install -r requirements42.txt"  
Run python manage.py check to ensure everything is set up correctly  
Run python manage.py makemigrations and manage.py migrate (setting up the databases)  
To run the server, do python manage.py runserver
